# Due Tattoos Website

This is the official website for **Due Tattoos**, built using **React.js**. It is a modern, dark-themed site designed to showcase tattoo artwork and manage bookings.

## 🚀 Quick Start

To run this project on your computer:

1.  **Install dependencies:**
    ```bash
    npm install
    ```
2.  **Start the website:**
    ```bash
    npm start
    ```
    The site will open at `http://localhost:3000`.

---

## 🎨 Color Palette

We use a "Studio Dark Mode" theme.

* **Background:** `#121212` (Rich Black)
* **Cards/Sections:** `#1E1E1E` (Charcoal)
* **Text:** `#E0E0E0` (Mist White)
* **Accent/Buttons:** `#C5A059` (Gold/Bronze)

---

## ✨ Key Features

* **Bilingual:** Users can switch between **English** and **French** instantly.
* **Gallery:** A responsive photo grid to show tattoo work.
* **Unique Design:** Uses angular shapes (Clip-path) for a modern, edgy look.
* **Booking System:** A contact form for clients to request appointments.

---

## 💳 Payment Method

The website uses a manual payment instruction method for bookings.

1.  The client fills out the booking form.
2.  A popup appears instructing them to send a deposit via **Sendwave** or **TapTap**.
3.  The client makes the transfer manually on their phone.

---

## 📁 Fonts & Icons

* **Font:** [Poppins](https://fonts.google.com/) (Must be imported in `index.html` or CSS).
